# Backups Directory - مجلد النسخ الاحتياطية

هذا المجلد يحتوي على النسخ الاحتياطية التلقائية للنظام:

## أنواع النسخ الاحتياطية

### النسخ اليومية
- `daily/` - نسخ احتياطية يومية (يتم الاحتفاظ بـ 7 أيام)
- تشمل: قاعدة البيانات، ملفات التكوين، الوثائق المرفوعة

### النسخ الأسبوعية
- `weekly/` - نسخ احتياطية أسبوعية (يتم الاحتفاظ بـ 4 أسابيع)
- نسخة كاملة من جميع البيانات

### النسخ الشهرية
- `monthly/` - نسخ احتياطية شهرية (يتم الاحتفاظ بـ 12 شهر)
- أرشيف طويل المدى

## النسخ الاحتياطي السحابي
- `cloud/` - نسخ محلية قبل الرفع إلى Google Drive
- يتم الرفع تلقائياً كل 24 ساعة

## تنسيق أسماء الملفات
```
jawdati_backup_YYYY-MM-DD_HH-MM-SS.zip
```

## الاستعادة
لاستعادة نسخة احتياطية:
1. أوقف الخادم
2. انسخ ملف قاعدة البيانات من النسخة الاحتياطية
3. استبدل الملف الحالي
4. أعد تشغيل الخادم

## الأمان
- النسخ الاحتياطية مشفرة
- كلمة المرور محفوظة في متغيرات البيئة
- تحقق دورياً من سلامة النسخ الاحتياطية
