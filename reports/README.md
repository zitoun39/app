# Reports Directory - مجلد التقارير

هذا المجلد يحتوي على التقارير المُولدة من النظام:

## أنواع التقارير

### تقارير العينات
- `samples/` - تقارير تحليل العينات الفردية
- تنسيق PDF مع الشعار الرسمي لـ ADE
- موقعة رقمياً ومختومة

### التقارير الإحصائية
- `statistics/` - تقارير إحصائية شهرية وسنوية
- رسوم بيانية ومؤشرات الأداء
- معدلات المطابقة وعدم المطابقة

### تقارير المطابقة
- `compliance/` - تقارير مطابقة المرسوم 11-219
- مقارنة مع المعايير الدولية (WHO, ISO)
- تقارير الانحرافات والإجراءات التصحيحية

### تقارير الجودة
- `quality/` - تقارير ضمان الجودة
- معايرة الأجهزة
- مراقبة الجودة الداخلية

## تنسيق أسماء الملفات

### تقارير العينات
```
Sample_Report_[SAMPLE_ID]_[DATE].pdf
مثال: Sample_Report_ADE2024001_2024-01-15.pdf
```

### التقارير الإحصائية
```
Statistics_Report_[PERIOD]_[DATE].pdf
مثال: Statistics_Report_Monthly_2024-01.pdf
```

## القوالب
- `templates/` - قوالب التقارير
- `header.html` - رأس التقرير مع الشعار
- `footer.html` - تذييل التقرير مع التوقيع
- `styles.css` - تنسيقات التقارير

## الأرشفة
- التقارير القديمة تُنقل تلقائياً إلى `archive/`
- يتم الاحتفاظ بالتقارير لمدة 10 سنوات
- فهرسة تلقائية للبحث السريع

## الأمان والخصوصية
- التقارير محمية بكلمة مرور
- تشفير ملفات PDF الحساسة
- سجل وصول للتقارير المُصدرة
- توقيع رقمي لضمان الأصالة
