# 1. تأكد من تثبيت Tesseract OCR منفصلاً:
#    - Windows: تحميل من https://github.com/UB-Mannheim/tesseract/wiki
#    - Linux: sudo apt-get install tesseract-ocr tesseract-ocr-ara
#    - macOS: brew install tesseract tesseract-lang
#
# 2. لدعم اللغة العربية في OCR:
#    - تحميل ملفات اللغة العربية من https://github.com/tesseract-ocr/tessdata
#    - وضعها في مجلد tessdata
#
# 3. لاستخدام PostgreSQL أو MySQL، قم بإلغاء التعليق عن المكتبات المناسبة
#
# 4. لاستخدام Redis للتخزين المؤقت، قم بإلغاء التعليق عن مكتبات Redis
#
# 5. تثبيت المتطلبات:
