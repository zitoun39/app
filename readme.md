# 🧠 README_PROMPT.md — مشروع "جودتي" LIMS + نظام الأرشيف الإلكتروني

## 📘 الوصف العام
مشروع **"جودتي – Jawdati"** هو نظام معلومات لإدارة مخابر مراقبة جودة المياه التابعة للجزائرية للمياه (ADE)، يتضمن وحدتين رئيسيتين:
1. **نظام LIMS** لتسجيل العينات والتحاليل والتقارير ومراقبة الجودة.
2. **نظام الأرشيف الإلكتروني** لأرشفة الوثائق الإدارية والفنية مع بحث OCR.

يعمل النظام **محليًا دون إنترنت**، ويدعم **اللغتين العربية والفرنسية**.

---

## ⚙️ المتطلبات الأساسية

يستخدم المشروع التقنيات التالية:

| المكوّن | التقنية |
|----------|-----------|
| Backend | Flask 3 + SQLAlchemy + Flask-Login |
| Database | SQLite |
| Frontend | HTML5 / Bootstrap / Jinja2 |
| PDF Reports | ReportLab + WeasyPrint |
| Archiving | FastAPI + Tesseract OCR |
| Backup | schedule + rclone (Google Drive) |
| Security | bcrypt + Flask-Login |
| Multilingual | ar / fr |

راجع ملف `requirements.txt` للمزيد من التفاصيل.

## 🧾 وحدات النظام

### 🔹 وحدة إدارة العينات والتحاليل (LIMS)
- تسجيل العينات برقم تسلسلي تلقائي حسب النوع والسنة.
- إدخال النتائج ومقارنتها بالمعايير القانونية (المرسوم 11-219).
- تحديد المطابقة تلقائيًا بالألوان (أخضر/برتقالي/أحمر).
- توليد تقارير ADE الرسمية (PDF) موقعة رقمياً.
- لوحة تحكم لعرض مؤشرات الجودة.

### 🔹 وحدة الأرشيف الإلكتروني
- رفع ملفات PDF/JPG/PNG مع بيانات وصفية.
- معالجة OCR (Tesseract) لاستخراج النصوص.
- بحث نصي شامل باستخدام FTS5.
- وسوم وتصنيف وتنظيم حسب السنوات.
- معاينات مصغّرة (Thumbnails).
