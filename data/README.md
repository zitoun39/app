# Data Directory - مجلد البيانات

هذا المجلد يحتوي على:

## قاعدة البيانات
- `jawdati.db` - قاعدة بيانات SQLite الرئيسية
- `init_db.sql` - سكريبت إنشاء قاعدة البيانات

## ملفات التكوين
- `config.json` - إعدادات النظام
- `parameters.json` - معايير الجودة والحدود المسموحة

## ملفات مؤقتة
- `temp/` - ملفات مؤقتة للمعالجة
- `uploads/` - ملفات مرفوعة من المستخدمين

## الأمان
- تأكد من عمل نسخ احتياطية دورية
- لا تحذف ملفات قاعدة البيانات يدوياً
- تحقق من صلاحيات الوصول للمجلد
